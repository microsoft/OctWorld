# Contributing to OctWorld

Please use GitHub issues for bug reports and feature requests, and pull requests
for proposed changes. Include a clear description and, where applicable,
reproduction steps or tests. Follow the existing code style and the installation
and usage instructions in the [README](README.md).

## Contributor License Agreement

Contributions to this Microsoft project are subject to the
[Microsoft Contributor License Agreement (CLA)](https://cla.opensource.microsoft.com).
Most contributions require you to agree to a CLA declaring that you have the
right to, and actually do, grant us the rights to use your contribution.
Follow any CLA instructions provided during pull request review.

## Code of Conduct

This project follows the [Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).

## Security

Do not report security vulnerabilities in public issues. Follow the
[security reporting policy](SECURITY.md).
